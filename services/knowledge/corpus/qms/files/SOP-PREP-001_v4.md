## 1. Purpose
This procedure defines library preparation for DNA and RNA specimens.

## 2. DNA Libraries
Germline panels and somatic calling use PCR-free WGS libraries.
PCR-free WGS requires at least 500 ng of input DNA measured by fluorometry.
Inputs between 200 and 500 ng may use the low-input PCR protocol, which is not valid for germline panels.
Target insert size is 350 to 450 base pairs.

## 3. RNA Libraries
RNA libraries for fusion analysis use stranded poly-A selection.
RNA input must be at least 100 ng with an integrity number of 7 or higher.
Degraded RNA below the integrity limit may be run with a documented deviation.

## 4. Indexing
Use unique dual indexes for every library to limit index hopping.
Record the index pair and lot number in the LIMS run sheet.
