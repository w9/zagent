## 1. Purpose
This retired procedure assessed sample quality for SNP array projects before sequencing replaced them.

## 2. Criteria
Arrays were accepted when the call rate was at least 0.98.
Coverage in the sequencing sense did not apply to array projects.

## 3. Retirement
This procedure was retired on 2023-06-30 when array work ended.
Use SOP-QC-001 for all sequencing quality review.
