Bulk RNA-seq expression analysis is a research service and is not available as a workbench application. It is run by the bioinformatics team on request.

Standard workflow

  1. Map reads with a splice-aware aligner against GRCh38 and the GENCODE annotation.
  2. Count reads per gene, respecting strand.
  3. Normalize counts and run differential expression when there are replicates.

Fusion calling from the same libraries is a separate application, rna-fusion.

Expect at least 50 million read pairs per library for expression work. Fusion calling can work with fewer.
