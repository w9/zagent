Expression values come in several units. Pick the one that matches the comparison you want to make.

UnitNormalizes forUse for
CPMLibrary sizeComparing the same gene across samples
FPKMLibrary size and gene lengthLegacy reports only
TPMGene length, then library sizeComparing genes within a sample

TPM values sum to one million in every sample, which makes within-sample proportions comparable. FPKM values do not, so FPKM is not comparable across samples.

Differential expression tools expect raw counts, not any of these units.
