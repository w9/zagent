Autopipe maps every released run automatically. Nobody needs to start it by hand.

What it does

  1. Watches the release queue for runs released under SOP-SEQ-001.
  2. Demultiplexes by unique dual index and writes FASTQ files in the standard directory layout.
  3. Aligns DNA libraries to GRCh38 and RNA libraries with a splice-aware aligner.
  4. Marks duplicates and writes CRAM files plus a metrics summary per library.
  5. Publishes library coverage and QC status so the workbench can query them.

Timing

A typical 30x genome takes about 6 hours to map. A run of 48 genomes is finished in about 14 hours.

Autopipe does not run readqc, somatic-snv, rna-fusion or germline-panel. Those are workbench jobs that a person confirms.

Failures

Mapping failures page the platform on-call. A run whose mapping failed shows no libraries in the workbench until it is fixed.
