Practical conventions for PCR-free WGS libraries that are not spelled out in SOP-PREP-001.

  • Library names end in the specimen role letter: T for tumor, N for normal.
  • Low-input PCR libraries carry the suffix LI and can never be used for germline panels.
  • Normalize libraries to 2 nM before pooling.
  • Pool no more than 48 genomes per run to keep coverage near 40x for tumor libraries.

If a germline panel request arrives for a low-input library, return the request and ask for a PCR-free library.
