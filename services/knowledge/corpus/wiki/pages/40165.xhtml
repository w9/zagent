Released FASTQ files follow one layout. Scripts that guess paths break when runs are re-demultiplexed, so use this layout.

// _L_R1.fastq.gz _L_R2.fastq.gz md5sums.txt]]>

Run IDs have the form YYMMDD_instrument_flowcell. Lanes are numbered from 1.

Re-demultiplexed runs get a suffix such as _redemux1; the original directory is never changed.
