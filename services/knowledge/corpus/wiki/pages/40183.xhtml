Ensembl and GENCODE stable identifiers start with a prefix that names the feature type.

PrefixFeatureExample
ENSGGeneENSG00000141510
ENSTTranscriptENST00000269305
ENSPProteinENSP00000269305
ENSEExonENSE00001146308
ENSRRegulatory featureENSR00000082541

A suffix such as .7 is the version of that record. Drop the version only when matching across annotation releases.

GENCODE uses the same identifiers as Ensembl for the same release.
